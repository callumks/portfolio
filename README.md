# callumks

Callum Stoddart's portfolio, served by GitHub Pages at https://callumks.github.io/portfolio/.

One static page, no build step: `index.html` holds the markup, styles and script. Project previews are live screenshots from microlink.io, except Callsheet, whose screens live in `images/callsheet/`. `experience.html`, `skills.html` and `projects.html` redirect old links to the home page.
